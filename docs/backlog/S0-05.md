## Objetivo

Preparar o banco nos três ambientes: local, staging e produção.

## Tarefas

- [ ] Criar o projeto Supabase de staging
- [ ] Criar o projeto Supabase de produção
- [ ] Instalar a Supabase CLI e subir o Supabase local (precisa do Docker)
- [ ] Criar a pasta `supabase/migrations/` no repositório
- [ ] Preencher o `.env.local` com as chaves do ambiente local

## Pronto quando

O Supabase local sobe com um comando, e os dois projetos na nuvem existem.
