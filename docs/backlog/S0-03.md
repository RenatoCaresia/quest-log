## Objetivo

Ligar o quality gate: nenhum código entra na `main` sem lint, tipos, testes e build passando.

## Tarefas

- [ ] Workflow `.github/workflows/ci.yml` rodando a cada push e Pull Request
- [ ] Dependabot semanal para npm e GitHub Actions
- [ ] Proteger a `main`: exigir Pull Request e o check "Lint, tipos, testes e build" verde antes do merge
- [ ] Bloquear push forçado e exclusão da `main`
- [ ] Nas configurações de Pull Request, deixar só **Create a merge commit** (sem squash), para preservar os commits de TDD
- [ ] Conferir que o selo do CI aparece verde no README

## Pronto quando

Um PR de teste com lint quebrado fica bloqueado, e o mesmo PR corrigido pode ser mergeado.
