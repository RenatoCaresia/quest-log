## Objetivo

Criar o projeto Next.js que vai receber todo o código do Quest Log.

## Tarefas

- [ ] Rodar `npx create-next-app@latest quest-log --ts --eslint --tailwind --app --src-dir --import-alias "@/*" --use-npm`
- [ ] Copiar os arquivos do kit inicial para a pasta do projeto
- [ ] Instalar o Vitest (`npm install -D vitest`)
- [ ] No `package.json`, adicionar aos scripts `"typecheck": "tsc --noEmit"` e `"test": "vitest run --passWithNoTests"`
- [ ] No `package.json`, adicionar `"engines": { "node": "26.x" }`
- [ ] No `.gitignore`, adicionar a linha `!.env.example`, para o arquivo de exemplo ir para o Git
- [ ] Criar o repositório público `quest-log` no GitHub e enviar o código

## Pronto quando

`npm run dev` abre a página inicial e o código está no GitHub.
