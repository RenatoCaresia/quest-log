## Objetivo

Configurar o Vitest e fazer o primeiro ciclo de TDD com uma regra já confirmada: o cálculo de nível. É uma fatia da QL-05 que prova, logo no começo, que o CI roda testes de verdade.

## Tarefas

- [ ] Configurar o Vitest (`vitest.config.ts`, com o alias `@/` do projeto)
- [ ] Remover o `--passWithNoTests` do script de teste assim que o primeiro teste existir
- [ ] Escrever com o Renato `docs/features/ql-05-xp-e-niveis.feature`, com um Esquema do Cenário para os níveis
- [ ] Ciclos de TDD para `calcularNivel(xp)` em `src/domain/progressao/`, um comportamento por vez:
  - [ ] 0 XP → nível 1
  - [ ] Limite do nível 2: 999, 1.000 e 1.001 XP
  - [ ] Limite do nível 3: 2.999, 3.000 e 3.001 XP
  - [ ] Limite do nível 5: 9.999, 10.000 e 10.001 XP
  - [ ] XP negativo: comportamento a decidir antes do teste
- [ ] Commits `red:`, `green:` e `refactor:` em cada ciclo
- [ ] PR com o CI verde

## Regras

Fórmula em `docs/regras-do-jogo.md`: XP total para o nível n = 500 · n · (n − 1).

## Pronto quando

O CI roda os testes de nível no PR, e o histórico mostra os ciclos de TDD.
